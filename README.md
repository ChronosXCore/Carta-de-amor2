# Carta Eterna — Para el Amor de Mi Vida 💕

Aplicación interactiva y carta digital animada desarrollada con **React**, **TypeScript**, **Tailwind CSS** y **GSAP**, optimizada especialmente para dispositivos móviles (iPhone).

## Estructura incluida en el paquete
- `imagenes/`: Las 10 fotografías originales integradas estáticamente en el build.
- `Audio/` y `public/contigo.mp3`: Canción de fondo (*Contigo - Los Panchos*).
- `src/`: Código fuente completo de la carta interactiva, galería de recuerdos, letra del bolero y dedicatoria final.
- `vercel.json`: Configuración lista para desplegar en Vercel con un solo clic.

## Cómo ejecutar en local
```bash
npm install
npm run dev
```

## Cómo publicar en GitHub + Vercel
1. Sube este proyecto a un repositorio de **GitHub** (o usa el botón **Export to GitHub** en la esquina superior derecha de Google AI Studio).
2. Entra en [vercel.com/new](https://vercel.com/new) e importa tu repositorio de GitHub.
3. Vercel detectará automáticamente **Vite** (`npm run build` / carpeta `dist`) gracias al archivo `vercel.json` incluido.
4. Haz clic en **Deploy** y obtendrás tu enlace público listo para compartir por WhatsApp o iPhone.
